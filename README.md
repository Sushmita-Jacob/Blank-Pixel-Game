# Looped In
This project was for Hack Club Campfire's Overdrive training! All code and artwork was made by humans using the GameMaker engine. Play as Loopy the turtle as he tries to escape a trap in the ocean. But don't fall through the gaps, or you may get stuck beneath their surface! (If you do, refresh the page to try again.)

Use the up key to jump and left/right keys to move.
